# Verified 1061 FRF container lineage

October 19, 2026. Evidence type: independently reproduced local byte transformation and exact comparisons. Machine-readable report: [frf-lineage-1061-2026-10-19.json](frf-lineage-1061-2026-10-19.json).

The three original 5Q0909144R / 1061 FRF containers decode to ZIP files whose sole ODX member is byte-for-byte identical to the corresponding archived ODX. ZIP CRC32 verification succeeds for all members. Both original-folder and clean-update-files FRF copies match exactly. All six ERASE/DATA payloads extracted from the newly decoded XML match the prior ODX-derived outputs. This closes the local FRF -> ZIP -> ODX -> payload lineage gate for H1/H2/H7.

## Inspected implementation and reproduction

Primary source: [bri3d/VW_Flash container decoder](https://github.com/bri3d/VW_Flash/blob/293f46d782bae2ced930497889b71eb782f122cb/frf/decryptfrf.py), commit `293f46d782bae2ced930497889b71eb782f122cb`, committed August 3, 2026. Read its complete 63-line implementation before adapting only the container transform. No downloaded source, legacy executable, firmware, installer, ECU script or seed/key script was executed.

The transform walks every encrypted byte, cycling the public upstream `data/frf.key` file. It updates a one-byte first state from the key byte, XORs the input with the first state, second state, key byte and `ff`, then updates the second state. Its output is an ordinary ZIP with Deflate-compressed XML. XML's `ENCRYPT-COMPRESS-METHOD=00` describes the inner payload and is consistent with this separately transformed outer container.

Reference files are held under ignored `analysis/1061/frf-source/`; their complete raw URLs and hashes are in the JSON report. The adapted transform's BSD license and copyright are preserved in `scripts/licenses/VW_Flash-BSD-2-Clause.txt`.

## Limits

These comparisons establish exact derivation from the local containers. They do not authenticate vendor origin, prove applicability or successful flashing, identify CPU silicon, infer any security access behavior, or turn the supplied flash update into a complete hardware dump. No conclusion is extended to another rack family or software version. The upstream key here is a public container-format reference file, not a recovered vehicle credential. The inner ODX and payload checks do not require interpreting or executing security metadata.
